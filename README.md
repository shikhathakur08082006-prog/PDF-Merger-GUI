PDF Merger GUI

Introduction

PDF Merger GUI is a simple Python-based application that allows users to merge multiple PDF files into a single PDF file. It provides an easy-to-use graphical interface for selecting PDF files and saving the merged document.

Problem Statement

Merging multiple PDF files manually can be time-consuming and inconvenient. This project provides a simple solution to combine multiple PDF files into one document quickly and easily.

Objectives

- To merge multiple PDF files into a single PDF.
- To provide a simple and user-friendly GUI.
- To allow users to select PDF files easily.
- To save the merged PDF at the desired location.

Technologies Used

- Python
- Tkinter
- PyPDF2
- File Dialog

Features

- Select multiple PDF files.
- Merge PDFs into one file.
- Choose the location and name of the output PDF.
- Simple graphical user interface.
- Displays a success message after merging.

Working of the Project

1. Open the PDF Merger application.
2. Select the PDF files that need to be merged.
3. The selected files are added to the PDF merger.
4. Choose the output location and file name.
5. The application merges all selected PDFs.
6. A success message is displayed after completion.

How to Run

1. Install Python.
2. Install the required library:

"pip install PyPDF2"

3. Open the project folder in VS Code.
4. Run "main.py".

Future Scope

- Add drag-and-drop functionality.
- Add PDF preview.
- Add page reordering.
- Add PDF splitting and rotation features.
- Improve the graphical interface.

Conclusion

The PDF Merger GUI is a useful Python mini project that demonstrates file handling, GUI development and PDF processing. It provides a simple way to combine multiple PDF files into a single document.
